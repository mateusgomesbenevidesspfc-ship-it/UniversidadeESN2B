# 🎯 Projeto Quiz - Java

Projeto desenvolvido para a disciplina **Algoritmos e Linguagem de Programação II**.

## 📚 Sobre o projeto

Sistema de Quiz desenvolvido em **Java**, executado pelo console/terminal, contendo 15 perguntas e alternativas.

## ⚙️ Funcionalidades

- 15 questões
- Escolha de alternativas
- Contagem de acertos
- Cálculo da porcentagem
- Mensagem de agradecimento

## 🛠️ Tecnologias

- Java
- ArrayList
- Scanner
- Estruturas `for` e `if`
